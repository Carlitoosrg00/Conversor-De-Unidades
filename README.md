# 🔄 Conversor de Unidades

## 📌 Descripción

Este proyecto consiste en una aplicación de consola desarrollada en Kotlin que permite realizar conversiones de divisas, distancias y temperaturas mediante un menú interactivo.

## ⚙️ Funcionalidades

- 💶 **Conversor de divisas:** euros a dólares, libras esterlinas, yenes y francos suizos.
- 📏 **Conversor de distancias:** kilómetros, metros, millas y centímetros.
- 🌡️ **Conversor de temperaturas:** Celsius, Fahrenheit y Kelvin.
- 🔁 Menú interactivo que permite realizar varias conversiones sin reiniciar el programa.
- ✅ Validación de datos y control de errores en las entradas del usuario.
- 🚪 Opción para salir de la aplicación.

## 🛠️ Tecnologías utilizadas

- Kotlin
- IntelliJ IDEA
- Programación estructurada
- Funciones, variables, estructuras condicionales y bucles.

## ▶️ Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta `UD01_Actividad04_Conversores` en IntelliJ IDEA.
3. Abre el archivo `src/Main.kt`.
4. Ejecuta la función `main()`.
5. Sigue las instrucciones del menú que aparece en la consola.
